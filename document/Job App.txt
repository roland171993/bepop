 1. UI Library for Faster Development 
 	=>Jetpack Compose
 2. State Management 
 	=> Local State: Jetpack Compose’s remember/mutableStateOf for UI-specific state.
 	=> Global State: ViewModel with StateFlow or SharedFlow
 	=> Server State: Remote Data: Use Paging 3 for pagination + Retrofit with coroutines
 					 Caching: Room for local DB + Repository pattern to sync with server 
 3. Router for Navigation
    => Jetpack Navigation
 4. Dependency Injection
 	=> Dagger Hilt
 5. Unit Testing
 	Framework: JUnit 5 + Mockito (with mockito-inline for Kotlin finals) 
	Coroutines: Use TestDispatcher (e.g., StandardTestDispatcher) to control virtual time 
	ViewModel: Test with TestCoroutineScope and InstantTaskExecutorRule for LiveData

 6- UI Testing
 	=> Compose Test (Jetpack Compose)
 	Tooling:
 		MockWebServer: For API response mocking 9.
 		HiltTestRule: For DI in UI tests 
 7. Mockable Testing
 	=> Mockito: Best for Java/Kotlin interoperability (use mockito-inline for final classes) 6.
